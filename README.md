# Projeto Valorant

Projeto acadêmico desenvolvido em HTML sobre o jogo Valorant.

## Sobre o projeto

O site apresenta informações sobre o jogo Valorant, incluindo agentes,
armas, mapas, modos de jogo, sistema de ranks, campeonatos, história,
comunidade e a equipe LOUD.

## Páginas

O projeto possui 11 páginas:

- Página inicial
- Agentes
- Armas
- Campeonatos
- Comunidade
- História
- Loja
- Mapas
- Modos
- LOUD
- Rank

## Estrutura

- `html/` — páginas HTML
- `img/` — imagens
- `Audio/` — arquivos de áudio
- `Video/` — arquivos de vídeo

## Tecnologias

O projeto foi desenvolvido utilizando somente HTML.

## Objetivo

Aplicar os conhecimentos de HTML aprendidos durante a disciplina,
incluindo tags semânticas, formulários, multimídia, tabelas,
listas e elementos de marcação avançada.
